# Source Code

This folder contains the Python programs used throughout the development of the project.

## Files

- **01_load_data.py** – Load the dataset into Pandas.
- **02_explore_data.py** – Explore the dataset and understand its structure.
- **03_clean_data.py** – Perform initial data cleaning.
- **recommender.py** – Build TF-IDF game profiles and make content-based recommendations for the SIDEQUEST web app.

The numbered scripts track the project's data preparation, feature engineering, model training, evaluation, recommendation, and API experiments.
