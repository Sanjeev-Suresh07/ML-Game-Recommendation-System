# 🎮 ML-Based Personalized Game Recommendation System

## 📌 Overview

This repository contains our end-semester Machine Learning project, which aims to recommend video games based on user preferences. The project is being developed progressively throughout the semester as we learn and implement new Machine Learning concepts covered in our coursework.

## 📊 Dataset

This project uses the **Steam Games Dataset** obtained from Kaggle.

The dataset (`games.csv`) is not included in this repository because of its large file size.

After downloading the dataset, place it in:

```
dataset/games.csv
```
